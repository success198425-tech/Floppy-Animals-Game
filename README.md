# 🐒 Floppy Animals — Beta 0.6
A fun, polished flappy-style game with animal characters, multiple themes, and power-ups!

## ✨ Latest Updates
### Beta 0.6 Changes
✅ **All Critical Fixes**
- Fixed GameOverView protocol conformance error
- Resolved missing braces & incomplete code blocks
- Fixed false collision/game over triggers
- Corrected unique sound effects for all animals
- Fixed inconsistent pipe gaps in landscape mode

🎨 **New Features**
- 5 Customizable Themes: Default, Neon Cyberpunk, Soft Pastel, Dark Luxury Gold, Cartoon Adventure
- Dynamic readable text colors for every theme
- Gun Power-ups: Green(3), Purple(5), Red(7) bullets with auto-fire
- Coin System: 100 Score = 1 Coin (saved locally)
- Difficulty-based High Score tracking
- Bypass/Invincibility toggle for testing
- Milestone alerts & special effects
- Realistic 3D bamboo pipes & smooth animal animations

🎮 **Game Info**
- 4 Playable Characters: Monkey 🐒 | Chicken 🐔 | Bird 🐦 | Eagle 🦅
- 3 Difficulty Levels: Easy | Medium | Expert
- Works on all iPhones — portrait & landscape support
- Full sound effects & haptic feedback support

## 🚀 How to Use
1. Select your character, difficulty, and favorite theme
2. Tap anywhere to jump
3. Collect guns to destroy pipes automatically
4. Earn coins and beat your high score!
